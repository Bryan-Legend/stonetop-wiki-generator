Inventário

Quando você se Equipa, marque uma quantidade de ◇ abaixo, em itens específicos ou em Indefinido.

  • Para uma carga leve (rápido e silencioso), marque até 3 ◇
  • Para uma carga normal, marque 4-6 ◇
  • Para uma carga pesada (barulhento, lento, quente, cansa rápido), marque 7-9 ◇

Indefinido

Quando você Tem o Necessário, mova uma marca daqui para um ◇ específico abaixo.

Equipamento

Use suprimentos para Recuperar-se, Acampar ou ter itens pequenos extras.

Posses, itens, espólio

Outras coisas

(animais, kits, itens escondidos etc.)

Itens pequenos

Cabem num bolso, numa bolsa ou numa bota. Quando você se Equipa, marque ☐ abaixo igual a 4+Prosperidade.

Indefinido

Quando você Tem o Necessário, mova uma marca daqui para os itens abaixo, ou gaste suprimentos para marcar um ☐ adicional.
